# Custom-themed Todo App!!

### A productivity tool with game-themed graphics to increase motivation and help monitor daily tasks in a pleasant environment.

*I made this so I don't get bored and abandon tasks after a day.*

### You can:
- Add your tasks and divide them into categories
- Choose your theme
- Get things DONE

### Right now, only the frontend is implemented >.<
